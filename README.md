# Ather Energy Market & Product Portfolio Analysis

## Overview

This project analyzes Ather Energy's market registrations, financial performance, and electric scooter product portfolio using Python, Pandas, and Power BI.

The project follows an end-to-end data analytics workflow, from data preparation and feature engineering in Python to business visualization and insight generation in Power BI.

The analysis focuses on:
- Registration trends
- Financial performance
- Vehicle sales
- Revenue
- Market share
- Gross margin
- Experience centres
- Product specifications
- Pricing
- Battery capacity
- Range
- Product-level value metrics
- Product positioning

## Project Objectives

1. Analyze Ather Energy's registration trends from 2023 to 2026.
2. Evaluate FY24-FY26 financial and business performance.
3. Compare Ather's electric scooter portfolio based on price, battery capacity, range, and performance.
4. Develop derived metrics to evaluate product value and positioning.
5. Build an interactive Power BI dashboard for business insights.

```text

Price per kWh = Ex-showroom Price / Battery Capacity (kWh)
